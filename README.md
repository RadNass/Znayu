# Znayu — математика без пробелов

**Статистика v0.9:** [подключение частной страницы статистики](docs/analytics.md), требуется однократный SQL в Supabase.

**Версия 0.12 · юридические страницы (черновики), экспорт прогресса и подготовленная серверная процедура удаления аккаунта**

Публичный сайт: https://radnass.github.io/Znayu/

Znayu помогает взрослым и школьникам находить пропущенные школьные математические навыки и изучать их без необходимости проходить всю программу с начала. Проект работает как статическое приложение на GitHub Pages. Диагностика и математическая проверка выполняются локально в браузере.

- Система проверки ответов, диагностики, маршрутов и Supabase не менялась.

## Что работает сейчас

- 15 тематических учебных модулей, 83 связанных навыка, наборы задач разных уровней сложности и отдельные открытые математические гипотезы.
- Два режима: взрослый и школьник.
- Пошаговые уроки, три уровня подсказок, краткая диагностика, карта знаний, прогресс и повторение.
- **Адаптивный пошаговый помощник прямо в уроке**: различает типовые заблуждения (например, ошибочное сложение знаменателей), объясняет конкретную ошибку, предлагает более простой шаг, умеет предложить подходящий базовый навык.
- **Математическая запись:** дроби отображаются вертикально в задании, подсказках и ответах ИИ (без исполнения HTML и сторонних библиотек).
- **Мини-проверка понимания:** по запросу предлагает другую задачу той же темы, проверяет ответ математическим модулем и не выдаёт формальную отметку «освоено» по одному успеху.
- **Проверка Cloudflare без лишних перерисовок:** виджет Turnstile сохраняется вне обновляемой области интерфейса; новый токен запрашивается после использования предыдущего. При необходимости пользователь всё равно может увидеть проверку Cloudflare.
- Форма «Спроси преподавателя»: кнопки «Объясни проще», «Почему так?», «Где ошибка?» и свободный текст. Без облачного сервиса работает ограниченный, но полностью локальный разбор по учебным правилам.
- Независимая проверка арифметических ответов. ИИ **не** выставляет правильность решения и не присваивает статус освоения.
- Прогресс взрослых можно синхронизировать с Supabase после входа через Google или email. Школьный режим хранит данные локально.
- **Подготовлена защищённая интеграция с языковой моделью** через отдельный Cloudflare Worker. Для реальных произвольных диалогов требуется настроить Worker, Turnstile и оплату API модели.

## Запуск без облачного ИИ

На Windows установите Node.js 18 или новее, откройте терминал в папке проекта и выполните:

```bash
npm start
```

Затем откройте http://localhost:4173/.

Проверка проекта:

```bash
npm test
npm run check
```

При публикации GitHub Pages сайт **сразу** работает с локальным пошаговым помощником, даже если сервер ИИ не настроен.

## Как подключить полноценного ИИ-преподавателя

GitHub Pages — статический хостинг: **никогда не добавляйте ключ OpenAI в JavaScript браузера, репозиторий или настройки GitHub Pages**.

Дополнительный сервер находится в `worker/src/index.js`. Его задача — принимать вопросы от приложения, проверять защитный токен Cloudflare Turnstile, ограничивать частоту запросов и безопасно передавать вопросы в OpenAI Responses API.

### Что потребуется

1. Аккаунт Cloudflare с включёнными Workers.
2. Аккаунт OpenAI API и оплачиваемый API-ключ (подписка ChatGPT Plus **не** оплачивает вызовы API).
3. Cloudflare Turnstile sitekey и secret с разрешённым доменом `radnass.github.io`.
4. Понимание, что ответы отправляются на сервер Cloudflare, а затем провайдеру ИИ; для детских профилей облачный ИИ **по умолчанию отключён**.

### Настроить Cloudflare Worker

Откройте терминал в папке `worker` проекта. Убедитесь, что Node.js установлен:

```bash
npx wrangler@latest login
npx wrangler@latest deploy
npx wrangler@latest secret put OPENAI_API_KEY
npx wrangler@latest secret put TURNSTILE_SECRET
```

При вводе секретов используйте защищённую команду `secret put`. Не размещайте их в чате, `.env`, коммитах или публичных файлах. В Cloudflare Turnstile создайте виджет с доменом `radnass.github.io` и скопируйте его **публичный** sitekey. Сервер проверяет `action=tutor` и домен выдачи токена.

Конфигурация Worker — `worker/wrangler.toml`: разрешён адрес GitHub Pages `https://radnass.github.io`, включён лимит 10 запросов в минуту на IP (приблизительный, не финансовый предел), студенческие облачные запросы по умолчанию заблокированы. При использовании собственного домена измените `ALLOWED_ORIGIN` и `TURNSTILE_HOSTNAME`.

### Соединить сайт с сервером

Измените **только публичные значения** в `src/tutor-config.js`:

```js
export const TUTOR_API_URL = 'https://znayu-tutor-api.<ваш-домен>.workers.dev';
export const TURNSTILE_SITE_KEY = '<публичный-sitekey-Turnstile>';
```

Опубликуйте эти изменения в `main`. GitHub Actions автоматически обновит сайт. В режиме взрослого появится статус **«ИИ»**. Каждый вопрос требует корректный одноразовый токен Turnstile. Если сервер не отвечает или защита не пройдена, программа использует локальные подсказки; числовые ответы по-прежнему проверяются самостоятельно.

### Безопасность и расходы

- Обязательная проверка `Origin`, Turnstile Siteverify, серверные лимиты, ограничение размера запроса и длины ответа.
- Ключ API хранится только в secrets Cloudflare Worker, не в браузере.
- При запросах к OpenAI выставлено `store:false`; персональные данные всё равно не следует вводить, а политика обработки данных провайдера должна быть изучена отдельно.
- Установите **лимиты расходования средств и оповещения** в личном кабинете OpenAI API. Turnstile и rate limit **не гарантируют** финансовый потолок.
- Без родительского согласия и мер защиты детей нельзя включать облачный ИИ для школьного режима. `ALLOW_STUDENT_AI` оставьте `false` до подготовки аккаунтов родителей, согласий, политики данных и контроля содержания.
- Это пилот: взрослые аккаунты и синхронизация уже есть, родительского кабинета пока нет. Запуск в детских организациях требует доработок и юридической проверки.

```text

│   ├── storage.js
│   └── styles.css

```
