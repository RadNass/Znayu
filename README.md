# Znayu («Знаю») — математика без пробелов

Рабочий прототип образовательного веб-приложения для восстановления пропущенных школьных знаний по математике. Интерфейс на русском. Один код для взрослых и школьников с разными режимами подачи.

![Статус](https://img.shields.io/badge/MVP-демо-6558e8)

## Что уже работает

- Два режима: взрослый и школьник (4–11 классы в интерфейсе).
- 13 учебных разделов и **72 навыка**, каждый с 3 интерактивными заданиями (всего 216).
- Поиск тем по названию и популярным запросам.
- Мини-диагностика: 3 направления по 7 вопросов (основа, алгебра, математика для ИТ), выявляющая навыки для повторения.
- Пошаговый урок с подсказкой, разбором ошибки и повторной попыткой.
- Проверка эквивалентных дробей, десятичных и смешанных чисел программным кодом.
- Карта 72 навыков со связями-предпосылками и описанием типичных ошибок.
- Повторные проверки по пройденным темам.
- Отдельное сохранение прогресса взрослого и школьника в `localStorage` браузера.
- Адаптивный дизайн для телефона и компьютера.
- Стартовый баннер со статистикой OECD и прямыми ссылками на исследования.
- Автоматические тесты содержания и математической проверки.

## Запуск

Требуется **Node.js >=18**. Никаких внешних пакетов и API-ключей нет.

```bash
npm start
```

Откройте http://localhost:4173 в браузере.

Тесты:

```bash
npm test
npm run check
```

Также можно разместить статические файлы на GitHub Pages. В репозитории есть workflow `.github/workflows/pages.yml`. Чтобы опубликовать, откройте **Settings → Pages → Build and deployment → Source: GitHub Actions**, а затем запустите workflow или отправьте коммит в `main`.

## Важные ограничения этой версии

Это **работающий MVP-прототип**, но **не промышленная платформа для детей**:

1. ИИ-преподавателя через API пока нет: ответы и подсказки созданы методически заранее, работают детерминированно. Это снижает ошибки и стоимость демонстрации. В следующей версии можно добавить безопасный серверный модуль генерации индивидуальных объяснений.
2. Нет регистрации, серверной базы данных, кабинета родителя и облачной синхронизации. Смена браузера или очистка хранилища сбросит прогресс.
3. Диагностика пока короткая и основана на типовых заданиях; это не психометрически валидированная адаптивная проверка.
4. Пользователь не может загрузить фото задачи или отправить свободный разговорный запрос ИИ.
5. Контент — пробная подборка, а не полная национальная школьная программа.
6. Не храните в такой демоверсии персональные данные несовершеннолетних. Перед публичным запуском детских аккаунтов необходимы авторизация, механизмы согласия и проверки доступа, защита данных, юридическая и методическая экспертиза.

## Ближайшие этапы

1. Адаптивный шаговый диагностический алгоритм и классификатор ошибок.
2. Аутентификация, PostgreSQL, серверное хранение прогресса, роли родителя и методиста.
3. Интеграция языковой модели для вариативных объяснений с проверкой математическим движком.
4. Поддержка задач по фото и визуальных манипуляторов дробей.
5. Локализация и валидация содержания под учебные программы.

Проект распространяется под лицензией MIT.


## Источники статистики на главной

- **50% 15-летних учащихся Казахстана ниже Level 2 по математике** и **31% в среднем по OECD**: [OECD PISA 2022, Kazakhstan Country Note](https://www.oecd.org/en/publications/pisa-2022-results-volume-i-and-ii-country-notes_ed6fbcc5-en/kazakhstan_8c403c04-en.html). В первоисточнике приведены доли **на уровне 2 и выше** (50% Казахстан; 69% OECD), поэтому ниже базового уровня — 50% и 31% соответственно.
- **25% взрослых с низкой математической грамотностью** (Level 1 или ниже, участвовавшие страны OECD): [OECD Survey of Adult Skills 2023](https://www.oecd.org/en/topics/adult-numeracy-skills.html).

Показатели относятся к различным возрастным выборкам и методикам. Их нельзя суммировать, и они не являются результатом диагностики посетителей сайта.

## Что пока не входит в прототип

ИИ-преподаватель, определение причин ошибок по произвольному тексту, учётные записи, синхронизация прогресса, родительский кабинет и адаптивная смена вопроса во время диагностики пока не реализованы. Для каждого навыка предусмотрены проверенные задания, фиксированные подсказки и независимая проверка ответа. Прогресс хранится только в браузере устройства.
